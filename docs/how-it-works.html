How It Works

Sensor input → crash decision → location capture → emergency alert

Detailed Functional Interaction of Components

1) MPU6050 → Impact Sensing Layer

The MPU6050 continuously streams acceleration and gyroscope values. The ESP32 reads this data and applies threshold logic to detect high-impact signatures while reducing false positives.

2) ESP32 → Decision & Control Layer

ESP32 is the orchestration core. It confirms crash likelihood, then transitions from monitoring mode to emergency mode and triggers GPS + GSM actions in sequence.

3) NEO-6M GPS → Localization Layer

After impact confirmation, coordinates are acquired from NEO-6M and formatted for alert messaging.

4) SIM800L GSM → Communication Layer

ESP32 sends AT commands to SIM800L to dispatch SMS (with coordinates) and optionally place emergency calls.

5) End-to-End Behavior

Crash detect → GPS acquire → SMS send → call trigger. This sequence keeps the system modular and testable.
