How It Works

Sensor input → crash decision → location capture → emergency alert

Flow Diagram

MPU6050
Impact Sensing
→
ESP32
Decision Logic
→
NEO-6M
GPS Coordinates
→
SIM800L

Step-by-Step

1

Read Motion Data

ESP32 continuously reads MPU6050 acceleration and orientation values.

2

Detect Crash Pattern

Threshold logic determines if the impact indicates a likely collision.

3

Get Location

GPS coordinates are retrieved from NEO-6M for emergency reporting.

4

Send Alert

SIM800L sends SMS and may place a call to emergency contacts.
