Step-by-Step Workflow

1

Continuous Sensor Monitoring

The ESP32 continuously reads acceleration and orientation values from the MPU6050. These readings are filtered to reduce noise and false positives.

2

Crash Detection Decision

If acceleration/tilt patterns exceed predefined safety thresholds, the event is treated as a potential crash and the emergency protocol starts.

3

Location Capture

The ESP32 requests current latitude and longitude from the NEO-6M GPS module so the location can be included in the emergency message.

4

Emergency Communication

The SIM800L sends an SMS (with coordinates) and can also place a call to predefined contacts for rapid response.

Design Goal

The system is optimized for demonstration simplicity: minimal hardware, clear logic flow, and practical emergency output. This makes it suitable for university prototype showcases.
