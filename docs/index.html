Accident Alert Module

ESP32-based embedded crash alert prototype for real-time accident detection and emergency notification.

Explore Project

Project Overview

This project detects high-impact crash events using an MPU6050 accelerometer/gyroscope, retrieves geographic coordinates via NEO-6M GPS, and triggers emergency communication through the SIM800L GSM module (SMS and call alert).

Core Components

ESP32

Main microcontroller handling sensor fusion, GPS parsing, and GSM communication logic.

MPU6050

Monitors acceleration and orientation changes to identify potential collision events.

NEO-6M GPS

Provides latitude/longitude so responders can locate the accident quickly.

SIM800L

Sends emergency SMS and can place a call to predefined contacts after detection.

System Workflow

  1. Continuously read acceleration/gyro data from MPU6050.
  2. Evaluate thresholds and crash heuristics on ESP32.
  3. On confirmed impact, fetch live coordinates from NEO-6M.
  4. Send emergency SMS with location and trigger call via SIM800L.

Use Case

Designed as a university demonstration prototype for intelligent transportation safety, this module shows how embedded systems can reduce emergency response time after road accidents.
