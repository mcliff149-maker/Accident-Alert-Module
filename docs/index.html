Project Overview

ESP32-based crash alert prototype that detects impact, captures GPS location, and sends emergency SMS/call alerts.

What This Project Does

The Accident Alert Module continuously monitors motion data from MPU6050. When a crash-like impact is detected, it fetches coordinates from NEO-6M GPS and sends emergency communication using SIM800L GSM.

Main Components

ESP32

Runs detection logic and controls sensor/GPS/GSM communication.

MPU6050

Captures acceleration and orientation to identify impact events.

NEO-6M GPS

Provides accident location coordinates in real time.

SIM800L GSM

Sends SMS and places emergency calls to predefined contacts.

Minimal System Sketch

[MPU6050] -> [ESP32 Logic] -> [GPS + GSM] -> [Emergency Alert]
