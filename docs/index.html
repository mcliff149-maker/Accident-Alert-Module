What This Project Does

The Accident Alert Module continuously monitors motion data from MPU6050. When a crash, or something mimicking a crash impact is detected, it fetches coordinates from NEO-6M GPS and sends emergency communication using SIM800L GSM to emergency services(Police or hospitals) and to the emergency contacts.
